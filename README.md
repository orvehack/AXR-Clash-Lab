# AXR Clash Lab 🧪

Laboratorio personal para estudiar partidas de Clash Royale, registrar resultados y analizar decisiones. La primera versión se centra en análisis de datos y revisión manual de partidas; no automatiza acciones dentro del juego ni interactúa con el cliente.

## Objetivos

- Guardar partidas y resultados en un formato sencillo.
- Registrar mazos, arenas, trofeos y notas sobre decisiones clave.
- Calcular estadísticas básicas de victorias y derrotas.
- Preparar una estructura para analizar partidas grabadas y comparar estrategias.
- Mantener el proyecto modular para poder añadir herramientas después.

## Estado actual

**Fase 0 — estructura inicial.** Este repositorio comienza con documentación. Todavía no hay un modelo entrenado ni un analizador de video implementado.

## Próximos pasos

1. Crear un registro local de partidas en CSV o JSON.
2. Añadir un analizador de estadísticas con Python.
3. Definir un formato de anotaciones para revisar repeticiones manualmente.
4. Construir pruebas con partidas de ejemplo y validar los cálculos.
5. Explorar análisis de video offline, respetando las reglas del juego y los derechos sobre las grabaciones.
