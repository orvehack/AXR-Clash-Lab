# AXR Calculadora

Aplicación Android nativa de calculadora, escrita desde cero para este repositorio.

## Funciones
- Suma, resta, multiplicación y división con prioridad matemática.
- Decimales, porcentaje, cambio de signo, borrar último carácter y limpiar.
- Interfaz oscura adaptada a pantalla móvil.
- Sin permisos de red, cuentas, anuncios ni bibliotecas de terceros.
- Icono vectorial original incluido en `app/src/main/res/drawable/`.

## Compilación
Abre esta carpeta como proyecto Gradle en Android Studio o ejecuta `gradle assembleDebug` con Java 17 y Android SDK 35 disponibles. El APK de depuración se genera en `app/build/outputs/apk/debug/app-debug.apk`.

Todo el código fuente y el recurso vectorial de esta carpeta se escribieron específicamente para AXR Calculadora; no se importan fuentes ni assets de otros proyectos.
